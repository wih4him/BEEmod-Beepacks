# TurretsTessersTetras charts

**[Open the chart viewer](https://wih4him.github.io/BEEmod-Beepacks/TurretsTessersTetras/charts/viewer.html)**: every chart for every item, one after another. Drag to move around, zoom with the wheel, a pinch or the buttons, and step with Prev and Next or the arrow keys.

Each item has a **box chart** (what the item does for each combination of its boxes and inputs) and, where it has a Cube Type, Button Type or Timer, a **types by boxes** chart. Each chart's notes and rules are at the bottom of the same picture.

Each chart was drawn for the pressing named in its title. Where an item changed later, its BEEmod description is the current word.
