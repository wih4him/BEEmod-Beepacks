# TurretsTessersTetras charts

Every item's charts, item by item:

- **Box chart**: what the item does for each combination of its boxes (Start Enabled, Start Active, Start Reversed and so on) and its inputs.
- **Types by boxes** (items with a Cube Type, Button Type or Timer): the same, for each type.

The notes and rules (what each colour and mark means, and the rules behind each cell) are at the bottom of each chart.

Each link opens the chart at full size: click the picture to zoom in or out, and scroll or drag to move around it.

Each chart was drawn for the pressing named on it. Where an item changed later, its BEEmod description is the current word.
