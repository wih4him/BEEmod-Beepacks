## Installing a pack

1. Download the pack's `.bee_pack` file from the table above. Don't use the green **Code > Download ZIP** button: that zip is the whole repository, not a package.
2. Put the `.bee_pack` file in BEEmod's `packages` folder as it is. Don't unzip it. If an older copy of the same pack is there, take it out first.
3. Restart BEEmod.

## Requirements

- Portal 2
- BEEmod 4.46.1

Each pack's README lists its items, its credits and anything it writes on your computer.

TurretsTessersTetras also has a box chart for every item: [TurretsTessersTetras/charts](TurretsTessersTetras/charts/README.md), with a viewer that steps through every chart.
